# AtrisBridge UI redesign

The current product direction treats AtrisBridge as a focused desktop utility rather than a dashboard. The shell prioritizes readable typography, workspace state, progressive disclosure, and compact detail panels. Technical transport diagnostics are intentionally moved away from the primary workflow and into advanced settings.

Branding uses the AtrisBridge mark derived from the Atris family shape, with a blue/cyan/indigo palette shared by the application accents and README wordmark.
