# AtrisBridge branding

- `public/brand/atrisbridge-mark.svg` is the compact product mark used by the desktop shell, favicon, and Tauri icon generation.
- `public/brand/atrisbridge-logo-light.svg` is the primary wordmark for light surfaces.
- `public/brand/atrisbridge-logo-dark.svg` is the dark-surface wordmark.
- Product UI accents use the same blue, cyan, and indigo family while keeping application surfaces predominantly graphite and flat.
